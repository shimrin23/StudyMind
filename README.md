# StudyMind

StudyMind is a Chrome extension for distraction-free YouTube study sessions.

## Features

- Manual Focus Mode timer
- Timer resets when Focus Mode is off
- Shows educational videos only
- Filters videos by your YouTube search
- Hides unrelated videos
- Hides Shorts and recommendations
- Hides entertainment content
- Hides common ads and skips skippable ads
- Tracks daily and weekly focus time
- Tracks shown study videos and hidden content
- Stores data locally

## Use

1. Start Focus Mode.
2. Search YouTube for a study topic.
3. Study without distractions.
4. Stop Focus Mode when finished.

## Install

1. Open `chrome://extensions`
2. Enable Developer mode
3. Click **Load unpacked**
4. Select the StudyMind folder
